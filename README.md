# VNA_Design
Work in Progress Design of a VNA 

The Subsystems and Simulations folder contains all files related to the research and pre fabrication testing/simulations of subsystems

VNA_Project folder contains all KiCad files of the board itself. Specifically open VNA_Project.kicad_pro to check out the design. KiCad files do not have RF subsystem layout as that will be done in ADS during testing.
